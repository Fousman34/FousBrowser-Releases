# Изменения

## V3 — 0.3.0

- Antidetect: резервный манифест при сетевых ошибках и ограничении GitHub API.
  При недоступности опубликованного архива используется исходный архив
  fingerprint-chromium той же версии. Проверки GPG и SHA-256 сохранены.
  Файлы сумм и подписи имеют резервные адреса в репозитории.
- Ошибка HTTP 404 объясняется явно и не вызывает бессмысленные повторные запросы.
  Загрузки запрашивают свежие ответы; имена архивов и версий проверяются до записи.
- Открытые вкладки и окна восстанавливаются штатным механизмом Chromium.
  Настройка включена для старых и новых профилей, переносится с экспортом и клоном.
  Выключение отключает принудительное восстановление и оставляет настройки браузера.
- Лаунчер открывает стартовую страницу отдельной вкладкой только при отсутствии
  сохранённой сессии. Повторный запуск не добавляет лишних вкладок.
- Встроенное расширение Manifest V3 заменяет страницу каждой новой вкладки.
  Постоянный публичный ключ сохраняет идентификатор расширения на других ПК.
  Нет разрешений на чтение сайтов, cookies, паролей или истории.
- Страница: часы, дата, вращающиеся орбиты, мягкое движение фона, анимация поиска;
  клавиша `/` переводит фокус в поиск. Поддержан режим уменьшенного движения.
- Интерфейс: плавное появление экранов, реакции кнопок и подсветка профилей,
  фиолетово-коралловые акценты.
- Добавлен поддерживаемый Chrome for Testing флаг `--disable-infobars` для
  скрытия уведомления о тестовой сборке. Это не меняет происхождение движка.
- Проверены 205 тестов ядра; проверены реальные Normal и Antidetect:
  новые вкладки и восстановление сессии через шифрование и повторные запуски.

Личные паспорта проекта и пользовательские данные в релиз не входят.
