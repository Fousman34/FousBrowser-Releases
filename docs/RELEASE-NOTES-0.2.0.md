# FousBrowser 0.2.0

- Проверка прокси перед запуском и отдельная кнопка диагностики.
- Исправлены HTTPS CONNECT/TLS и обработка SOCKS5; соединения закрываются вместе с профилем.
- Зашифрованный экспорт и импорт `.fousprofile` при одинаковом мастер-пароле.
- Перенос legacy DPAPI-ключа браузера; App-Bound Encryption может потребовать повторного входа.
- Исправлена стартовая страница на Windows, обновлена иконка и фиолетово-коралловая тема.
- Статус движка обновляется после установки без перезапуска лаунчера.
- Усилены проверки контейнеров и защита от одновременного изменения данных профиля.

Для Windows x64: установщик `*-setup.exe` или `.msi`. Контрольные суммы — `SHA256SUMS`.

Старое хранилище совместимо; не удаляйте `%APPDATA%\FousBrowser` при обновлении.
Экспортируйте профиль после остановки. Для импорта в другое хранилище мастер-пароли должны совпадать.
Архив сохраняйте под новым именем. Не все браузерные сеансы гарантированно переносятся между компьютерами.

Проверено: 196 тестов ядра, 0 падений, 2 диагностических теста пропущены;
живые HTTP и SOCKS5 через Rust-мост; создание хранилища и запуск профиля.
Проверка на отдельной чистой Windows и полный визуальный прогон пока не выполнены.
