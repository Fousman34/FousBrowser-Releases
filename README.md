# FousBrowser

**Лаунчер профилей для браузерных движков с шифрованием данных на диске.**

FousBrowser — это не браузер. Это «мозг» системы: отдельное приложение, которое управляет
профилями, запускает под ними браузерный движок с нужными параметрами, шифрует все данные
и следит за обновлениями.

---

## Статус проекта

Работает **только в Windows** (10 и 11). Готовые установщики публикуются в разделе
[Releases](../../releases): `FousBrowser_0.3.0_x64-setup.exe` (установка в профиль
пользователя, права администратора не нужны) и `.msi`. Движок для профилей Antidetect
ставится самим лаунчером из раздела «Обновления движков».

| Компонент | Состояние |
|---|---|
| Хранилище (Argon2id + XChaCha20-Poly1305) | готово (M1) |
| Интерфейс входа, терминальная тема, анимация печати | готово (M2) |
| Управление профилями (создание/удаление/клонирование) | готово (M3) |
| Привязка прокси (SOCKS5 / HTTP / HTTPS) | готово (M3) |
| Локальный прокси-мост с аутентификацией | готово (M6) |
| Восстановление после сбоя | готово (M7) |
| Шифрование данных профилей на диске | готово (M4) |
| Запуск и остановка движка, «Остановить все профили» | готово (M5) |
| Обновление Normal-движка (официальный канал) | готово (M8) |
| Обновление Antidetect-движка через GitHub Releases + GPG | готово (M8) |
| CI, установщики и релизы по тегу | готово (M9) |

## Что это такое

| Часть | Роль |
|---|---|
| **Лаунчер** | Управляет профилями, шифрует данные, проверяет обновления, запускает движок |
| **Движок Normal** | Стоковый Chromium без патчей — для повседневного сёрфинга |
| **Движок Antidetect** | Chromium со сменой fingerprint (User-Agent, Canvas, WebGL, шрифты, timezone, WebRTC) |
| **Профиль** | Изолированный набор данных браузера, на диске хранится только в зашифрованном виде |

## Возможности

- **V3 / 0.3.0** — восстановление открытых вкладок и окон включено по умолчанию
  для новых и существующих профилей. Настройка находится в форме профиля;
  отключение возвращает управление настройкам запуска самого браузера.
- **Каждая новая вкладка** — встроенная страница FousBrowser: часы, дата, поиск,
  анимированные орбиты и фон. Работает локально, расширение не имеет доступа к сайтам.
- **Надёжная загрузка Antidetect** — резервный манифест при недоступности API GitHub
  и зеркало исходных байтов при ошибке загрузки. GPG и SHA-256 обязательны для всех источников.

- **Мастер-пароль** — минимум 12 символов, проверка на сложность. Из пароля выводится ключ
  шифрования через **Argon2id**. Пароль не хранится ни в каком виде.
- **Шифрование всего** — профили, список профилей, настройки прокси. Без правильного пароля
  не расшифровывается ничего.
- **Профили** — создание, удаление с подтверждением и безвозвратным стиранием, клонирование
  с новым fingerprint-зерном.
- **Запуск и остановка** — профиль расшифровывается во временный каталог, под ним стартует
  движок, а после закрытия окна данные шифруются обратно и открытая копия стирается.
- **Остановить все профили** — одна кнопка: все браузеры закрываются параллельно, данные
  каждого шифруются обратно, неудачи перечисляются отдельно.
- **Своё оформление вместо чужого** — окно профиля называется `FousBrowser — <профиль>`
  и носит значок проекта; стартовая страница тоже своя: знак FousBrowser и одна строка
  поиска, без чужих логотипов и заголовков.
- **Прокси на профиль** — SOCKS5, HTTP или HTTPS; настройки хранятся зашифрованными.
- **Проверка прокси** — диагностика перед запуском и отдельная кнопка. Проверяйте
  соответствие протокола порту: HTTP и SOCKS5 часто используют разные порты.
  HTTPS-прокси подключается через TLS с проверкой сертификата.
- **Перенос профиля** — зашифрованные `.fousprofile`, экспорт после остановки,
  импорт только с тем же мастер-паролем. Переносятся данные и настройки, сохраняется
  отпечаток; импорт создаёт новый UUID и перешифровывает данные. Legacy DPAPI-ключ
  перепривязывается к новой Windows. App-Bound Encryption и некоторые сеансы могут
  потребовать повторного входа. Предел архива — 20 ГиБ / 100000 файлов.
- **Восстановление после сбоя** — если лаунчер упал, при следующем запуске осиротевшие
  расшифрованные папки будут зашифрованы обратно или удалены (по настройке).
- **Два независимых канала обновлений** — Normal через официальный канал Chromium;
  Antidetect через GitHub Releases с обязательной проверкой GPG-подписи.
- **Интерфейс** — тёмная терминальная эстетика, моноширинный шрифт, текст печатается
  посимвольно, без системных всплывающих подсказок.

## Первый запуск

1. Лаунчер показывает экран приветствия — предустановленных профилей нет.
2. Нужно придумать **мастер-пароль**: минимум 12 символов, желательно буквы + цифры + спецсимволы.
3. Всё, что вы создадите дальше, шифруется этим паролем.

> ### Восстановления пароля не существует
>
> Ключ шифрования выводится из мастер-пароля и больше нигде не сохраняется. Если пароль
> забыт — данные профилей восстановить невозможно. Это осознанное свойство системы,
> а не недоделка. Сохраните пароль в менеджере паролей.
>
> Неудачные попытки входа **не приводят к удалению данных**: включается нарастающая задержка,
> и после 100 неудач подряд лаунчер ждёт вашего явного подтверждения продолжить. Данные
> остаются на диске зашифрованными.

## Установка

Готовые сборки публикуются в [Releases](../../releases). Установка **не требует** Rust, Node.js,
компиляторов или каких-либо зависимостей, и **не требует прав администратора**.

### Windows

1. Скачайте `FousBrowser_x.y.z_x64-setup.exe` (или `.msi`) из Releases.
2. Запустите установщик — установка идёт в профиль пользователя.
3. **SmartScreen.** Windows может показать «Windows защитила ваш компьютер»:
   нажмите **Подробнее** → **Выполнить в любом случае**. Это стандартное поведение для
   приложений без платной подписи Authenticode.
4. Запустите FousBrowser из меню «Пуск».

Требуется WebView2 — он уже входит в Windows 11 и обновлённые Windows 10. Если его нет,
установщик предложит доустановить.

### Другие системы

macOS и Linux не поддерживаются: сборки для них не выпускаются. Лаунчер
работает только в Windows 10 и 11 (нужен WebView2 — он входит в Windows 11
и обновлённые Windows 10).

## Как обновляются движки

Два независимых канала — у них разные источники и разные проверки.

| Канал | Источник | Проверка перед установкой |
|---|---|---|
| **Normal** | официальный манифест Chrome for Testing | TLS при загрузке и структура архива; контрольных сумм источник не публикует |
| **Antidetect** | Releases этого репозитория | GPG-подпись списка контрольных сумм встроенным публичным ключом, затем сверка SHA-256 архива |

Движок Antidetect — это подписанное зеркало сборки ungoogled-chromium с патчами подмены
отпечатка (проект [fingerprint-chromium](https://github.com/adryfish/fingerprint-chromium)).
Байты архива публикуются без изменений, их сумма и подпись лежат в самом релизе, а текст
лицензии (BSD 3-Clause) записывается рядом с установленным движком.

Установка идёт в staging-каталог: работающая версия не трогается, пока архив не скачан,
не проверен и не распакован. Прежняя версия остаётся на диске — указатель можно вернуть
назад, если новая почему-то не запустится.

## Где хранятся данные

Пользовательские данные никогда не пишутся в папку установки:

| Что | Расположение |
|---|---|
| Данные и настройки | `%APPDATA%\FousBrowser` |

Структура хранилища:

```
vault/vault.enc        зашифрованные метаданные (профили, прокси, настройки)
vault/profiles/<uuid>/ зашифрованные данные профилей
vault/index.json       открытый индекс: uuid, временный путь, статус (без имён и настроек)
vault/attempts.json    счётчик неудачных попыток входа
browsers/              скачанные движки (Normal, Antidetect)
```

## Сборка из исходников

Нужны **Rust** (stable, MSVC toolchain), **Node.js 20+** и для Windows — Visual Studio Build Tools
с workload «Desktop development with C++».

```
git clone git@github.com:Fousman34/FousBrowser-Releases.git
cd FousBrowser-Releases/launcher
npm install
npm run tauri dev
```

Подробности архитектуры — в `docs/ARCHITECTURE.md`, модель угроз — в `docs/THREAT-MODEL.md`,
текущее состояние этапов и способ проверки — в `docs/PROGRESS.md`.

## Устранение типичных проблем

| Симптом | Решение |
|---|---|
| «Windows защитила ваш компьютер» | **Подробнее** → **Выполнить в любом случае**: приложение не подписано платным сертификатом |
| Окно пустое или белое | Не хватает WebView2 — установите «Microsoft Edge WebView2 Runtime» с сайта Microsoft |
| Забыт мастер-пароль | Восстановление невозможно. Смотрите раздел «Первый запуск» |
